# Portefølje

Min personlige portefølje, bygget for å vise frem prosjektene mine og litt om hvem jeg er.

🔗 **Live:** [lenke kommer etter deploy]

## Om prosjektet

En React-basert portefølje med gjenbrukbare komponenter for skjermbilde-visning, teknologi-tagger og en trinnvis prosjekt-karusell.

## Teknologier

- React + TypeScript
- Tailwind CSS 4
- React Router
- Vite
- Hostet på GitHub Pages

## Kjøre lokalt

```bash
npm install
npm run dev
```
